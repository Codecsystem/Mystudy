dilworth定理
偏序集里，链指任意两个元素都可比的一组元素，反链指任意两个元素都不可比的一组元素。
Dilworth 定理：最少用多少条链覆盖所有元素 = 最大反链大小。
对偶形式：最少用多少个反链覆盖所有元素 = 最大链大小。
若用 DAG 表示偏序，链内相邻元素只要求“可达/可比”，不一定要有原图直接边，所以必要时先做传递闭包再建二分图。
通常考察二维偏序，按一维排序后，最大链/最大反链常可以转成 LIS/LDS；最少链划分则由最大反链给出。

hall定理
设二分图左右点集为 X,Y。Hall 定理：存在一个匹配覆盖左侧全部 X 的充要条件是，对于任意 S 属于 X，都有 |N(S)|>=|S|。
含义是：左侧任意一批点合起来能选择的右侧候选点，数量不能少于这批左侧点，否则鸽巢原理必然匹配不完。
若 |X|=|Y|，并且存在覆盖 X 的匹配，则这个匹配大小为 |X|=|Y|，因此也是完美匹配；左右大小不等时只能说覆盖左侧，不叫完美匹配。
在树上的推广：如果我们选择k个点和树的叶子做匹配，要满足 对u子树 子树中的选择的点<=子树的叶子数

排列诸结论
1.交换两个数的顺序，会使排列的逆序对数+1/-1 奇偶性变换
2.一个长度为 n 的排列，其逆序对数的奇偶性等于n-c c是置换环数
置换环：把排列看成映射 i->p_i，从一个下标不断跳到 p_i，直到回到起点得到的环；下标[l,r]包含了[l,r]的所有元素只是一个封闭块，不一定是单个置换环
3.交换大小为x，y的两个块 对逆序对的贡献为x*y-2k,k为原来块间的逆序对数
4.最优交换次数 $K$：将排列 $P$ 分解为若干个不相交的置换环。设环的个数为 $C$，则将 $P$ 排序为 $(1, 2, \ldots, N)$ 的最小交换次数为：$$K = N - C$$
5.置换环内交换：如果你交换同一个环内的两个元素，这个环一定会分裂成两个更小的环。
6.置换环间交换：如果你交换不同环的两个元素，这两个环会合并成一个大环。
